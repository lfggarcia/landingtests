# Nativa Press Co.

Sitio generado a partir del template `complex/seasonal-juice` para **acme**. Es un proyecto Next.js completo y autocontenido — no depende del catálogo de Agencia D para correr, compilar ni desplegar.

## Empezar

```bash
npm install
npm run dev
```

## Build y producción

```bash
npm run build
npm run start
```

No requiere variables de entorno ni servicios externos — se puede conectar el repo directamente a Vercel (o cualquier host compatible con Next.js) y desplegar sin pasos adicionales.

## Editar contenido

`src/templates/seasonal-juice/config.json` es el snapshot guardado al asignar este template — textos, colores, links y secciones salen de ahí. Cambios ahí no requieren tocar componentes.
